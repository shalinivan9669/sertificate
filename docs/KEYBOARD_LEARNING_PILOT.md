## Изоляция и воспроизведение

Тест: `tests/keyboard-learning-browser.mjs`. Он требует `NODE_ENV=test`, `OT_ALLOW_TEST_SEED=1`, свободный порт 3107 и отдельный `OT_KEYBOARD_ARTIFACT_ROOT` внутри игнорируемого `.data/keyboard-pilot-*`. Для каждого запуска создаётся новая UUID-папка и новая `e2e.sqlite`; приложение и fixture-сервис используют только её. Повторное использование общей `.data/e2e.sqlite` отсутствует. Локальный сервер и Chrome закрываются в `finally`.

Фактическая копия: `.data/keyboard-pilot-20260907-211511/.output`. Её fixture-source зафиксирован из git `9dc293d` отдельно от изменяемого рабочего дерева; миграции 001–009 скопированы в подпапку `migrations`. Это важно при параллельном добавлении migration 010: новый рабочий `audit()` уже ожидает её колонки, тогда как проверяемая сборка и изолированная схема относятся к предыдущей версии. Новые исходники B52 в этот прогон не вошли.

Существующий `tests/e2e-fixtures.ts` создаёт только явно синтетические аккаунты и опубликованную тестовую версию с текстовым уроком и двумя вопросами. Запись, прогресс и попытка появляются после настоящих действий UI. SMTP, CRM, платежи, счета и внешние уведомления отключены; никакие реальные документы не выпускаются.

На подготовленной копии запуск выполняется из корня репозитория:

```powershell
$env:NODE_ENV = 'test'
$env:OT_ALLOW_TEST_SEED = '1'
$env:OT_KEYBOARD_ARTIFACT_ROOT = (Get-Content .data/keyboard-pilot-root.txt -Raw).Trim()
Remove-Item Env:VERCEL,Env:VERCEL_ENV,Env:TURSO_DATABASE_URL,Env:TURSO_AUTH_TOKEN -ErrorAction SilentlyContinue

```

Для подготовки новой копии достаточно скопировать существующую совместимую `.output` в уникальную `.data/keyboard-pilot-*` без изменения исходного артефакта, поместить совместимые SQL в `migrations`, а `git archive` соответствующей версии (`server`, `shared`, `tests/e2e-fixtures.ts`, `package.json`) распаковать в `fixture-source`. Никакая сборка Nuxt, `prepare` или изменение работающего сервера для повторения не нужны. Параметр `BROWSER_PATH` позволяет явно указать установленный Chrome; по умолчанию используется стандартный Windows-путь.
