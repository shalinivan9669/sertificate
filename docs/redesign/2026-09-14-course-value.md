# Ценность курса вместо публичной цены

По запросу владельца суммы в обзорных блоках заменены пользой конкретного направления для работы. В `shared/public-course-value.ts` подготовлены отдельные формулировки для всех 20 направлений на русском и казахском языках. Это описание назначения подготовки, без обещаний гарантированной сертификации или результатов обучения.

Главная, каталог, паспорт программы и страницы направлений используют новую подачу. В сравнительном шаблоне `/second` и резервном Civic-шаблоне суммы также убраны. У паспорта программы основное действие — «Запросить стоимость», рядом пояснение «Стоимость по запросу».

Кнопки передают направление, город и формат в `/contacts?request=price#request-form`. Форма показывает заголовок запроса стоимости и добавляет это намерение в существующее поле комментария заявки. Новые поля API не потребовались. Цены утверждённых версий, расчёты заказов и финансовые документы не изменялись.

Проверено:

- Lint и проверка типов прошли.
- 48 проверок браузера, 26 снимков: RU/KK, ширина 1440, 1280, 820, 390 и 360 px; отсутствие видимых сумм и горизонтальной прокрутки, 20 различных формулировок, сохранение контекста всех четырёх точек входа в заявку. Ошибок выполнения и гидратации нет.
- Отправка формы проверена с перехваченным ответом API: в сообщении сохраняется намерение узнать стоимость. Реальная заявка не отправлялась.
- Дополнительно 2 проверки с синтетической опубликованной платной версией: сумма не показывается, действие запроса основное, ссылка на существующее оформление сохраняет выбранную версию.
- Полный набор: 308 предметных тестов прошли; очистка временной базы одного набора завершилась ошибкой Windows `EBUSY`. Отдельный повтор этого набора прошёл полностью, 32/32 вместе с очисткой. Код тестируемой системы из-за этого не менялся.
- В первом браузерном прогоне исправлен селектор самого проверочного сценария: кнопка находится внутри `.ed-page-header`, а не `.ed-page-heading`. Результат повторной проверки успешный.
- Production-сборка прошла. Проверены 314 сформированных страниц с блоками курсов: видимых сумм нет. SEO-проверка прошла на 558 публичных страницах; проверка 19 491 ссылки на ресурсы не выявила отсутствующих файлов.
