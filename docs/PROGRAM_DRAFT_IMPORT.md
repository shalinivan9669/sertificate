# Импорт учебного черновика

Редактор программ `/admin/programs` поддерживает локальные JSON-пакеты формата
`ot-center-program-draft-v1`. Импорт доступен редактору и администратору через
существующую авторизацию и MFA. Пакет не добавляет отдельный сайт или каталог.

1. Откройте редактор и выберите «Загрузить учебный пакет».
2. Проверьте название, язык, число уроков и вопросов в предпросмотре.
3. Нажмите «Открыть как новый черновик». Несохранённые поля редактора будут заменены.
4. Проверьте содержание и сохраните. Сервер создаст отдельную версию с текущим
   пользователем в качестве автора. Ранее сохранённые версии останутся доступными.
5. После предметной проверки заполните утверждённые параметры программы и дату
   проверки содержания, затем используйте обычный процесс рецензии и публикации.

Выбор файла и предпросмотр не записывают данные в базу. Файл ограничен 500 000 байт
UTF-8. Допустима начальная BOM; структура, идентификаторы, варианты ответов и ссылки
на правильные варианты проверяются перед открытием. Сервер повторно проверяет
сохраняемый материал, права доступа и разрешённые хосты медиа.

Внешняя структура содержит только три поля:

```json
{
  "format": "ot-center-program-draft-v1",
  "programId": "ohrana-truda",
  "data": {}
}
```

`data` — полная структура `ProgramData` из `server/services/catalog.ts`; пустой
объект в примере не является готовым пакетом. Импорт не принимает ID версии,
пользователя, утверждающего или состояние публикации. Значение `reviewedAt`
сбрасывается даже при наличии в файле. Отсутствующий `billingBasis` получает
значение `learner`.

Неизвестная длительность сохраняется как `durationHours: null` только в черновике.
Передача на рецензию и публикация требуют утверждённого целого числа часов.
`priceMinor: null` и `accessModel: "manual"` сохраняют стоимость по запросу и
ручное основание предоставления доступа. Импорт не включает оплату, письма,
выдачу документов или публикацию автоматически.

Банк вопросов содержит ключи ответов. Храните полный импортный пакет в закрытом
рабочем каталоге, передавайте уполномоченному редактору и загружайте через его
кабинет. Не размещайте такой файл в `public`, публичном Git-репозитории или
публичных CI-артефактах. Учебные тексты без банка и методические объяснения можно
передавать отдельно для рецензии.
