## Содержание и назначения

| Раздел меню | Что помогает сделать | Куда ведёт |
|---|---|---|
| Начать обучение | Выбрать программу, обучить команду, вернуться к занятиям; продление, тендер, сжатые сроки | `/program-selection`, `/b2b`, `/cabinet#learning`, реальные информационные страницы задач |
| Направления | Найти одно из 20 направлений; три смысловые группы и поиск по названию | `/courses/{реальный slug}`; общий каталог `/courses` |
| Формат и город | Посмотреть онлайн, очное или выездное обучение, выбрать городскую страницу | При известном городе — `/{city}/{format-page}`; города — `/{city}` |
| Моё обучение | Материалы, проверка знаний, документы, заказы, организация | `/cabinet#learning`, `#assessments`, `#documents`, `#orders`, `/cabinet/organization` |
| Центр и помощь | Аккредитация, связь, статьи, условия, конфиденциальность | `/licenses`, `/contacts`, `/blog`, `/public-offer`, `/privacy`, публичные телефон и почта |

На широком экране раздел выбирается в вертикальном оглавлении. На телефоне используется подписанный нативный select, а разворот превращается в последовательность блоков. Меню открывается кнопкой «Меню» на всех ширинах. Кнопки «Обучение», «Направления» и «О центре» в широкой шапке сразу открывают нужную рубрику.

## Учебные назначения

Глобальное меню не выдумывает ID курса, попытки или документа. «Проверка знаний» ведёт в раздел кабинета с назначенными курсами. Каждая строка получает реальный ID из `/me/enrollments` и открывает `/learn/{id}/pre-test`. Открытие условий не создаёт попытку. Проверки допуска и запуск таймера остаются на существующей странице подготовки.

Для документов и заказов добавлены стабильные якоря к существующим блокам кабинета. Вход сохраняет полный адрес возврата, включая query и hash. При отсутствии назначений показывается пустое состояние с пояснением; наличие пункта меню не обещает доступ к невыданному курсу.

## Контекст и поведение

- Город определяется только из справочника: сначала параметры городского маршрута, затем query, затем сохранённый выбор.
- В учебные переходы передаются валидные город и формат. Старые programId, versionId, произвольные query и частные ID из текущей страницы не копируются в новое направление.
- Явный городской контекст и формат сохраняются после успешного перехода. Выбранный город остаётся видимым и после посещения страницы центра без query.
- Формат подписан как предпочтение, а не как обещание доступной версии или группы в городе.
- Нативный dialog делает остальную страницу неактивной. Tab/Shift+Tab замыкаются в меню; стрелки/Home/End переключают рубрики. Escape и кнопка закрытия возвращают фокус к инициатору.
- Шапка с закрытием остаётся видна при прокрутке. Для сфокусированных элементов предусмотрен отступ под неё.
- Прокрутка фоновой страницы блокируется только на время открытого меню, затем восстанавливается. Учебная страница и форма не размонтируются при открытии или изменении размера меню.
- Обычный переход, в том числе на текущий адрес, закрывает меню. Открытие ссылки в другой вкладке не закрывает текущий разворот.
- При reduced motion отсутствуют анимация открытия и увеличение иллюстрации.

## Карта реализации

| Файл | Роль |
|---|---|
| `components/editorial/EditorialNavigation.vue` | Диалог, рубрики, поиск, назначение ссылок, фокус и прокрутка |
| `composables/useEditorialMenu.ts` | Общие `open`, `section`, `show(section)`, проверенный контекст и локализованные ссылки |
| `assets/css/editorial-navigation.css` | Композиция меню, шапка, адаптация; использует существующие `--ed-*` |
| `layouts/default.vue` | Кнопка меню и быстрые входы в рубрики |
| `pages/cabinet/index.vue` | Якоря и переходы к условиям проверки назначенных курсов |
| `pages/ui-kit.vue` | Запуск того же настоящего меню из UI kit |
| `scripts/editorial-menu-browser.mjs` | RU/KK, пять разделов, восемь размеров, фокус, поиск, контекст и сохранение формы |
| `scripts/editorial-menu-learning.mjs` | Вход из меню, реальное назначение, условия теста, документы и заказы на синтетической базе |

Для открытия из нового компонента используйте `const { show } = useEditorialMenu()` и `show('start' | 'programs' | 'places' | 'learning' | 'center')`. Не создавайте вторую копию диалога. Для новых направлений обновляйте группы меню вместе с общим реестром; названия берутся из `courseDirections`, а не дублируются вручную.

Снимки и машинные отчёты находятся в `artifacts/editorial/menu/`. `menu/report.json` отделяет проверки вёрстки от переходов, а `menu/learning-report.json` — авторизованный сценарий на изолированных данных. Нативные клавиатуры телефонов и физический шарнир складного устройства этим прогоном не проверяются; используются соответствующие области браузера.
