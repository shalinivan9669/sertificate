Сюда добавляйте файлы для блока "Лицензии и сертификаты".

Имена файлов по умолчанию:
- `license.pdf`
- `certificate.pdf`
- `accreditation.pdf`

Если нужно изменить имена файлов или добавить новые, правьте:
- `config/licenses-files.js`

Если для карточки файла нет, поставьте `null` в соответствующей позиции.

Можно передать объект:
- `file`: путь к PDF для скачивания
- `preview`: путь к картинке-превью (например, `/Screenshot_8.jpg`)
- `previewAlt`: подпись для `alt`
