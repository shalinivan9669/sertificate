# T03. Проверка исходных данных подрядной бригады

Редакционный чек-лист заказчика; не разрешение на работы. Версия 07.10.2026.

| Проверка | Что зафиксировать | При расхождении |
|---|---|---|
| Предмет задания и объект | Где и какие работы планируются | Уточнить задание до сопоставления обучения |
| Фактический состав | Обезличенные роли; совпадение согласованной и прибывшей команды | Передать замену на повторную проверку |
| Подготовка по функции | Программа, результат, категория и проверенный источник | Не считать один общий документ достаточным |
| Выдающая сторона | Наименование организации и подтверждение документа | Запросить подтверждение; не объявлять подделкой без проверки |
| Организатор работ | Кто решает вопросы допуска и организации | Установить ответственного компетентного лица |
| Изменившиеся условия | Новая задача, оборудование, сезон, смена | Проверить необходимость дополнительных мер |
| Решение по открытым вопросам | Ответственный, срок, подтверждение закрытия | Не закрывать вопрос отметкой «письмо отправлено» |

Для крыши, газоопасных работ, электроустановок и иных специальных работ нужен отдельный компетентный разбор применимых требований. Этот список их не заменяет. Реальные документы проверяются в защищённом контуре.
